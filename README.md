# Портфолио проектов по кибербезопасности | Школа 21

В данном репозитории собраны практические проекты, выполненные в рамках направления кибербезопасности в «Школе 21». Репозиторий будет еще дополнятся

---

## Последовательный обзор проектов

### 1. Основы сетей. Часть 1 — «Первый опыт»
* **Цель:** Изучение фундаментальных принципов построения компьютерных сетей, моделей OSI/TCP/IP и работы в виртуальной среде эмуляции.
* **Выполненные задачи:**
* Выполнен расчёт IP-адресов в двоичной системе счисления и подбор сетевых масок (CIDR) для пользовательского, серверного и технологического сегментов сети.
* Развёрнута и настроена эмуляционная среда GNS3 с импортом образов оборудования Cisco IOS 3745.
* Проведён анализ генерации и передачи Multicast-запросов и ICMP-пакетов с детальным разбором полей L2/L3 через Wireshark.
* Исследована работа протокола ARP, проанализированы структуры ARP-таблиц и изучена логика проведения атак класса MITM / ARP-spoofing.
* **Стек:** GNS3, Cisco IOS 3745, Wireshark, IPv4, ARP, ICMP.

### 2. Основы сетей. Часть 2 — Прикладные протоколы
* **Цель:** Настройка прикладных сетевых служб, обеспечение удаленного доступа и организация статической маршрутизации.
* **Выполненные задачи:**
* Сконфигурирована статическая маршрутизация на цепочке маршрутизаторов (R1–R2–R3) с проверкой сквозной связности трафика.
* Развёрнут и настроен сервер точного времени NTP, синхронизировано системное время и проанализированы транспортные метки пакетов (UDP 123).
* Настроена служба DNS с использованием виртуальных интерфейсов Loopback, реализовано разрешение доменного имени (`my.site`) и проанализированы структуры DNS-запросов.
* Настроен сервер DHCP на оборудовании Cisco для автоматического распределения пула из 50 IP-адресов и проанализирован процесс DORA.
* Настроено безопасное подключение по SSH (VTY, учётные записи, генерация RSA-ключей), проанализировано 3-стороннее рукопожатие TCP (SYN, SYN-ACK, ACK) и проведено сравнение трафика SSH с открытым протоколом Telnet.
* **Стек:** Статическая маршрутизация, NTP, DNS, DHCP, SSH, Telnet, Wireshark, GNS3.

### 3. Основы сетей. Часть 3 — Продвинутый сетевой детектив
* **Цель:** Построение отказоустойчивых корпоративных сетей с использованием виртуальных подсетей, агрегирования каналов, динамической маршрутизации и резервирования шлюзов.
* **Выполненные задачи:**
* Сконфигурированы виртуальные сети VLAN (802.1q) на модулях EtherSwitch, разделены клиентские сегменты, настроены Trunk-порты и внедрены базовые механизмы защиты от VLAN Hopping.
* Объединены физические порты коммутаторов в агрегированные каналы EtherChannel для увеличения пропускной способности и обеспечения отказоустойчивости.
* Настроена динамическая маршрутизация OSPF в многосегментной сети с применением интерфейсов Loopback, изучен алгоритм Дейкстры и внедрена аутентификация MD5.
* Реализовано резервирование первого узла маршрутизации с помощью протокола HSRP (роли Active/Standby) с настройкой виртуального IP-адреса.
* **Стек:** VLAN (802.1q), EtherChannel, OSPF, HSRP, Cisco EtherSwitch, GNS3.

### 4. Основы сетей. Часть 4 — Стальная кошка
* **Цель:** Проведение сетевой криминалистики (network forensics), анализ аномалий в дампах трафика и автоматизация генерации пакетов.
* **Выполненные задачи:**
* Проведён глубокий анализ дампа сетевого трафика SMB: определены версия диалекта SMB, Session ID, учётные записи и MAC/IP-адреса участников сессии.
* Выявлена активность несанкционированного удаленного доступа (Reverse Shell) в записанном pcap-файле, установлены IP-адреса источника и назначения, используемый протокол и переданные команды.
* Разработан скрипт на языке Python с использованием библиотеки Scapy для низкоуровневого формирования и отправки кастомного TCP-пакета на локальный порт с последующим перехватом и созданием pcap-дампа.
* **Стек:** Wireshark, Python, Scapy, SMB, Reverse Shell Analysis, PCAP.

### 5. Защита последнего сервера Linux в мире
* **Цель:** Системное администрирование ОС семейства Linux, автоматизация сбора метрик и комплексное укрепление защиты (hardening).
* **Выполненные задачи:**
* Написан скрипт на Bash (`get_all_info.sh`) для автоматического сбора данных о системе (установленные пакеты, процессы, открытые порты, версия ядра) с упаковкой результатов в архив `OS_RESULT.tar`.
* Сконфигурирована модель разграничения доступа (DAC), созданы группы и пользователи с ограниченными правами (`secret_users`, `default_users`), настроены правила `sudoers` и сервисы Apache2.
* Организован регулярный автоматический мониторинг системы с помощью утилит Logwatch, Postfix и планировщика Cron для ежедневной отправки логов.
* Выполнено укрепление защиты ОС: отключена аутентификация по паролю в SSH в пользу приватных/публичных ключей, сконфигурированы правила фильтрации трафика в `iptables` (цепочка INPUT).
* **Стек:** Linux (Kali/Ubuntu), Bash, SSH, iptables, Postfix, Logwatch, Crontab, apache

### 6. Основы Windows — Мастер Окна
* **Цель:** Администрирование безопасности ОС Windows, управление групповыми политиками, шифрование данных и настройка Брандмауэра.
* **Выполненные задачи:**
* Настроены политики паролей (длина, сложность, срок действия) через локальные групповые политики (`gpedit.msc`) и написан PowerShell-скрипт (`get_sec_pol.ps1`) для аудита настроек безопасности.
* Внедрено полнодисковое шифрование томов Windows с помощью BitLocker с защитой ключей доступа.
* Ограничены права пользователей и настройки UAC: заблокирован сетевой вход для встроенных учётных записей, ограничены права на выключение системы и RDP-подключения.
* Настроены правила Брандмауэра Windows (блокировка HTTP 80, FTP 21, ICMP ping и разрешение RDP 3389) и разработан PowerShell-скрипт (`get_fw_rules.ps1`) для автоматического экспорта действующих правил.
* **Стек:** Windows OS, PowerShell, Group Policy (GPO), BitLocker, Windows Defender Firewall, MMC.

### 7. Введение в криптографию — Скрытая очевидность
* **Цель:** Изучение фундаментальных принципов прикладной криптографии, механизмов кодирования, хеширования, а также симметричного и асимметричного шифрования.
* **Выполненные задачи:**
  * Отработано преобразование данных между десятичным, шестнадцатеричным и текстовым представлениями в кодировках ASCII, UTF-8 и Base64.
  * Исследованы математические свойства логической операции XOR (исключающее ИЛИ) и её обратимость; реализован скрипт на Python для побайтового выполнения операции XOR над строками.
  * Изучены принципы работы криптографических хеш-функций (MD5, SHA-1, SHA-256, SHA-512), механизмы защиты с использованием «соли» и выполнено восстановление пароля по хешу.
  * Проведён криптоанализ кастомного алгоритма шифрования на Python (`crypto.py`) с восстановлением исходного зашифрованного значения.
* **Стек:** Python, криптографические хеш-функции (SHA-512, MD5, SHA-1), XOR, симметричное и асимметричное шифрование, ASCII, UTF-8, Base64, криптоанализ.
